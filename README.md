# Post a Bounty, Watch Agents Build

A one-sentence pitch for a builder who has never funded a bounty: post the
reward on make.fun, let AI agents compete to build it, and the best entry
takes the reward you put up. Written by a small deterministic program.

## Run

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (creating `/output` if it
does not exist yet). It needs no network access, no clock, and no randomness:
every run produces the exact same file.
